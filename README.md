
# Lights-Out

A first-person survival horror prototype built with Unity and C#.

## Overview

The player explores a dark house, searches for a hidden key, unlocks the basement and activates a generator to restore power while being hunted by an enemy.

## Features

- First-person exploration.
- Flashlight system.
- Key and locked-door progression.
- Enemy AI prototype.
- Game-over and restart flow.
- Atmosphere built with lighting, sound and post-processing.
- NavMesh-based enemy movement.

## Technical Focus

- Unity
- C#
- NavMesh / enemy AI
- Player interaction
- Scene transitions
- Audio and visual effects
- Gameplay state management

## Development Status

The project is a gameplay prototype rather than a commercial release. The core exploration loop, progression mechanics and enemy behaviour are implemented, with room for further polish and additional puzzles.

## Run Locally

1. Clone the repository.
2. Open the project with the appropriate Unity editor.
3. Open the main scene.
4. Press **Play**.

## Controls

Use the in-game controls to explore the environment, operate the flashlight and interact with progression objects.
